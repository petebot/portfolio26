# Synchronic Studio

## The premise

Creative work rarely moves in a straight line. Studio time, daily writing, errands, research, and half-formed ideas often live in separate tools—making the larger pattern difficult to see. Synchronic treats those activities as parts of one practice.

## The product

The app is organized around five verbs: Observe, Practice, Roam, Tend, and Reflect. Together they form a calm operating system for logging studio sessions, capturing excursions, writing daily reflections, managing creative tasks, and reviewing progress over time.

## The system

- Local-first storage keeps the core practice useful without a network connection.
- Optional Supabase sync supports continuity across devices.
- A SvelteKit interface serves the web while Tauri packages the same product as a focused desktop app.
- Shared date, reminder, and practice-session logic keeps daily and weekly views consistent.

## The design direction

The visual language borrows from instruments, celestial diagrams, and archival notebooks: restrained color, warm metallic accents, deliberate motion, and verb-led navigation. The interface is designed to feel reflective without becoming precious or slow.

## What I owned

I shaped the product model, interaction system, visual direction, frontend architecture, desktop packaging, data synchronization, and ongoing release workflow. The work moves continuously between concept, design, engineering, testing, and real daily use.
